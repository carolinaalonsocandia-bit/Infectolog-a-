## Las cuatro reglas que resuelven casi todo el tema

1. **En el inmunosuprimido: las vacunas inactivadas son seguras; las vivas están contraindicadas.**
2. **Dos vacunas vivas parenterales: el mismo día, o separadas por al menos 4 semanas.**
3. **"Dosis puesta, dosis que cuenta": un esquema interrumpido se continúa, nunca se reinicia.**
4. **Neumococo: conjugada primero, polisacárida después.**

**Todo el calendario, las presentaciones disponibles y las indicaciones financiadas en Chile
los define el Programa Nacional de Inmunizaciones del MINSAL: verificar siempre la versión
vigente antes de indicar una vacuna.**
